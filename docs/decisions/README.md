- [0030](0030-trierarch-plugin.md) **Trierarch plugin.** The trierarchs' plugin on the server side, optional, its own package and process beside squadrons, a ship of each fleet it serves (fleet:read, fleet:commission, crew:assign, crew:run, labels:define, labels:assign, scopes:declare), owned by argo; placement across people's machines is the organisation's label-based ruleset in the plugin, switched per fleet as squadrons; its own small database holds only each fleet's connection and switch, everything else lives in the fleet; commissions trierarch ships for an actor holding trierarch:join, a scope it declares and enforces, or argo, and gives their starting prompts; labels machines from their reports every trierarch ship `trierarch=machine` and its own `trierarch=plugin`, declaring `trierarch=*` to `trierarch=*`, withdrawn when off or deleted; assigns requests oldest first by optimistic claim to the fitting trierarch with the most room, writing a reason when none fits; places a request given back again without the trierarchs that gave it back; flags a machine silent past a threshold, never moves a final assignment.
