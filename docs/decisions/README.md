# Decisions

Current state only; history is in git. To change a decision, edit its file and its line here in the same commit. Decisions keep one numbering across the trains' repositories; the full index is aeolus-fleet's [docs/decisions/README.md](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/decisions/README.md).

- [0030](0030-trierarch-plugin.md) **Trierarch plugin.** The trierarchs' plugin on the server side, optional, its own package and process beside squadrons, a ship of each fleet it serves (fleet:read, fleet:commission, crew:assign, crew:run, labels:define, labels:assign, scopes:declare), owned by argo; placement across people's machines is the organisation's label-based ruleset in the plugin, switched per fleet as squadrons; its own small database holds only each fleet's connection, switch, enabled models (0063) and usage history, everything else lives in the fleet; keeps usage per hour as each trierarch sends it to its ship, pruned by the fleet's retention, read by fleet:read; commissions trierarch ships for an actor holding trierarch:join, a scope it declares and enforces, or argo, and gives their starting prompts; labels machines from their reports every trierarch ship `trierarch=machine` and its own `trierarch=plugin`, declaring `trierarch=*` to `trierarch=*`, withdrawn when off or deleted; assigns requests oldest first by optimistic claim to the fitting trierarch with the most room, writing a reason when none fits; places a request given back again without the trierarchs that gave it back; flags a machine silent past a threshold, never moves a final assignment.
- [0063](0063-model-governance.md) **Model governance.** Per fleet, the trierarch plugin holds the fleet's enabled models, exact model ids in its own table, empty being no rule; in a fleet with a rule it places only a request naming an enabled model, or naming none on a trierarch whose default for the harness is enabled, else writes `model disabled: ...`, and the check before a request answers the same; only placing is checked, so assigned and running crews keep their model; every session reads the set, enabling and disabling take fleet:manage; rejected a deny list, families, a fleet setting in core, taking back assigned requests.
