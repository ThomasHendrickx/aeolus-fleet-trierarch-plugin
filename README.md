# Aeolus trierarch plugin

`@aeolus-fleet/trierarch-plugin` brings the machines of an [Aeolus](https://github.com/ThomasHendrickx/aeolus-fleet) fleet in and places each crew request on a machine that fits, where that machine's trierarch crews it. It is optional: a ship of each fleet it serves, beside core, reaching the fleet only through its public API. How to run it and its API: [packages/trierarch-plugin/README.md](packages/trierarch-plugin/README.md). For the product, see [aeolus-fleet](https://github.com/ThomasHendrickx/aeolus-fleet).
